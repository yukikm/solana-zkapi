# SDK distribution guide

The installation, browser-worker bundling, deployment artifact loading and
source-build procedures are maintained in the
[SDK distribution guide](https://github.com/yukikm/solana-zkapi/blob/main/docs/getting-started/sdk-distribution.md).
For a complete first application, follow
[SDK setup](https://github.com/yukikm/solana-zkapi/blob/main/docs/getting-started/sdk.md).

This package includes compiled ES modules and TypeScript declarations. It is
distributed as a release tarball; deployment proof assets are separate inputs.
Use the independently verified release and retain its exact archive and lockfile.
