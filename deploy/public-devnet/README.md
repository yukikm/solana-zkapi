# Public Devnet deployment files

Start with [operator setup](../../docs/getting-started/proxy-operator.md) and
[gateway configuration](../../docs/getting-started/gateway.md).

This directory contains nginx templates, [systemd units](systemd/README.md),
immutable profile inputs and [upstream distribution notices](upstream-notices/PROVENANCE.md).
The native macOS client download is not a server bundle.

Operational guides:

- [Monitoring and recovery](../../docs/getting-started/operations.md)
- [Backup and restart](../../docs/getting-started/backup-and-restart.md)
- [Archive storage](../../docs/getting-started/archive-storage.md)

Deployment files are templates for a prepared Devnet operator. See
[support](../../docs/support.md) for the release scope.
