# Server-only Node fetch compatibility

The public gateway rejected Node standard `fetch` because it supplies a lone `Sec-Fetch-Mode: cors` header. The native opt-in branch now accepts that exact header, alongside metadata-free native requests. Explicit Origin still requires the reviewed browser allowlist. Other Fetch Metadata and mode values cannot enter the native branch; exact routes, invitation/budget/financial guards, recovery and cancellation remain unchanged.

The pre-deployment read-only `/relay-status` matrix returned **200** without Fetch Metadata, **400** for lone `Sec-Fetch-Mode: cors`, **200** for reviewed same-origin browser metadata, and **200** for explicit reviewed Origin. Successful responses reported admission suspended, recovery enabled and readiness not checked. These results identify the compatibility failure, not operator readiness.

The focused suite passed **42/42**, zero skips, in 1.975 seconds, including actual Node-fetch SDK preflight through a local ingress fixture and browser/native denial cases. The initial 41-pass/one-failure run is preserved: its fixture attempted an ineffective Node-fetch Host override. The corrected fixture preserves actual headers/body and rewrites only Host, matching the trusted reverse proxy; no runtime check was weakened to repair it. Independent review found no concrete security regression.

Only `scripts/devnet-browser-relay/host.ts` changes the server runtime closure: SHA-256 `82673784a2565a981e1f27d720f353593dee2fd9c6dca8d99eda7577c206bff5`. The other changed file is the gateway test. The operator installed this exact file with an old-hash guard and backup. The R03 installation returned success, recorded the matching before/after hashes, and kept new admission disabled.

The actual public follow-up passed **6/6** checks: standard Node fetch returned 200; forbidden browser Origin and cross-site metadata each returned 400; reviewed same-origin metadata returned 200; budget status returned the active seven-request/7,000,000-micro-USDC grant with zero reservations and zero currently available admissions; and RPC returned the expected Devnet genesis. These were read-only requests with zero financial actions.
