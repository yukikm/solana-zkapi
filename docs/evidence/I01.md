## Commands / 結果

以下はrepo rootから（Go/Node baselineは指定directoryへ移動）。RustがPATHにない環境ではrustupのenvを読み込む。

```sh
git submodule update --init --recursive
python3 scripts/check_upstream.py
cargo test --locked --release --manifest-path vendor/ethereum-zkapi/protocol/rust/Cargo.toml
cargo test --locked --release --workspace --manifest-path vendor/ethereum-zkapi/Cargo.toml
```

結果：source pin PASS、protocol 49 tests PASS、CLI/indexer/server 102 tests PASS、計151 tests PASS。元の実Groth16 round-tripも含む。これらはSolanaのSVMや会計移植試験ではない。

`vendor/ethereum-zkapi` で `npm ci --ignore-scripts`、`npm run test:sdk`：309 tests PASS。

`vendor/ethereum-zkapi/zkapi-clientd` で `GOTOOLCHAIN=local go test ./...`：依存 `go-ethereum@v1.17.5` の配信redirect先 `storage.googleapis.com` が環境のHTTP policyによりForbidden。cmd/clientdとinternal/zkapiを実行できない。許可済みproxyを迂回せず停止。

初回は環境umask 077により「公開権限のlock file」を作るテストも失敗。`umask 022` を設定した再実行でinternal/config、internal/relay、internal/serverがPASS。vendorのテストや実装は変更していない。CIにもumaskを明記した。Go全体を合格とはしない。
